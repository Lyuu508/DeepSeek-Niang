# v0.0.5 安装与实体设备验收

从本版本 Releases 直接下载 `DeepSeek-Niang_0.0.5_windows-x64-setup.exe` 和 `DeepSeek-Niang_0.0.5_android-arm64-isolated-test.apk`，对照 SHA256SUMS.txt。二者 SHA 必须与 BUILD-RESULTS.json 相同。签名为原仓库测试身份，Windows 自签名不是公共 CA 认证发行商；不要关闭安全软件。

Android `io.local.deepseekcompanion.test2` / versionCode1005，应覆盖已安装的 v0.0.4 扫码测试版。官方 apksigner 门禁实际比较新旧 APK 证书为 `fefb57342751c7bd5ef8271e4a8b09f8702c0285e0120e8407b557d20dbbf153`。它不能覆盖 v0.0.1 正式包或旧 .test；不卸载、不清数据。两端均升级，保证 schema8 配对同步。

以下均为**待用户实体设备验收**，不是自动化通过记录：

- 先独立备份，覆盖安装后确认人格 UUID、聊天、手动重要记忆、好感度和配对记录均在；手机仍能独立聊天。
- Windows 启动后打开“关系与日常”：检查当前虚拟活动、状态、开始/更新时间、已提交进度和心情；原聊天保持在中央。
- 创建三天计划，或使用自动模式的初始三日安排。当前活动结束后开始；每步约20分钟，下一步至少24小时后开始，重启不归零。
- 暂停→等待→恢复，检查同一任务和进度。取消当前任务及关联计划，不应再次启动该步骤。失败任务可手动安全重试。
- 退出电脑应用，手机等待心跳过期后应显示离线/状态过期。重启电脑恢复原检查点，离线时间不能显示已经学完、看过视频或完成网页任务。
- 开启主动交流选择自然模式，模型开关先保持关闭，等待有来源活动结束；同一来源只能一条消息。免打扰/滚动日限额有效。
- 在本机 Key 设置配置自己的 DeepSeek Key，另行允许模型主动分享，查看 purpose=life 实际 usage。无 Key 或网络断开，虚拟日程仍工作；不要求发送 Key 给协作者。
- 将 Token 预算设0，模型请求必须停止准备；关闭主动开关后不继续发送，包括迟到生成结果。未知请求不能自动重试消耗额度。
- 手机与网线电脑处于可互访 LAN，扫描已有安全配对流程同步：同一计划/活动/记忆/分享不复制；手机标为已读，回执可传回电脑，设备的通知状态单独保存。
- 启用系统通知并保存后允许 OS 权限；测试最小化窗口时有新分享，通知仅显示通用提示；点击/展开应用查看来源。系统拒绝权限时仍能读应用内分享。Android 强制停止后不保证推送，本版无云推送/保活。
- 更换人格，计划、兴趣、日记、分享和用量完全隔离；切回历史还在。选过去日期能查看当地日记，实际聊天/虚拟活动/应用情绪来源可区分。
- Windows 小窗口、Android 竖屏/横屏、刘海/导航栏和中文键盘都不遮挡输入和扫码。

Hosted Windows 安装启动、原生编译、APK 官方签名校验会写入发布报告；真实 API、家庭 LAN、实体 Android 安装/覆盖升级/通知呈现不由浏览器 Mock 证明。出现问题保留具体错误码、版本、系统信息及脱敏日志，不上传私人 SQLite 或 Key。
