# 生活与主动分享 Token / 费用

日程、计时、兴趣规则、资料回顾、关系计算、结构化日记和同步：不调用模型，Token 为0。重要记忆使用已有本地规则和源事件。

主动生成需要同时满足：用户开启主动交流、模式非关闭、单独开启模型、本机可读取 Key、本人格的来源完成事件、原主机权限、无前台聊天/近期互动、免打扰/关系冷却/滚动日上限，以及 Token 余额。没有 Key 时仍推进合法本地生活，不创建收费请求。关闭模型时可以发送有来源的简短本地规则分享。

默认模型开关关闭。日预算4096 Token（旧用户未配置时默认），可设0–100000；实际每次输出上限256，输入只取人格/关系/情绪/完成来源及最多2条允许 API 的相关记忆。以 UTF-8 字节作为保守输入上界，另加协议余量和输出上限，余额不足先暂停，不能先请求后检查。时间窗口为滚动24小时，跨午夜、时区修改不能刷额度；界面另提供近7天分类统计。

仅实际 provider usage 为 measured；流断开或进程退出用量未知，保留预留并标记 uncertain，不自动重试未知 POST。429 仅沿用原客户端对明确拒绝的一次有限重试。成功/失败均记录 life purpose、模型、任务/来源、实际输入输出；没有价格快照时费用保持 null/未知，不将未知报为免费。

回环 HTTP 使用合成 Key 和模型回复，覆盖中文流与usage落库，不产生真实 API 费用。真实 DeepSeek 由用户在本机安全存储 Key 后测试；不要求用户发送 Key 到聊天。具体模型当前价格不在本版写死。
