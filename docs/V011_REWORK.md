## 实现与验证范围

| 项目 | 当前结果 |
| --- | --- |
| Windows、Android 界面 | Chromium 打开了双端九个页面，覆盖浅色、深色、字号、回收站、配对和设置操作。Android 检查 295px 起的竖屏、横屏和模拟键盘区域。渲染使用合成数据和明确的 IPC 夹具，具体系统栏和物理触控有待设备验收。 |
| 图片与插件 | Chromium 实际解码图片并验证拖放、粘贴、预览、移除与授权。Rust 回环服务检查真实 JPEG 请求、私有上传引用和 DeepSeek 处理路径。插件导入、确认权限、启停、撤回及卸载在夹具中回归。 |
| 视频 | 聊天和视频中心使用同一条链路。12 MiB 以内、最长 5 分钟的 MP4 可提交原片，其余设备可解码的视频按时间范围抽帧。修订了原片失败后的手动切换入口。Chromium 解码 FFmpeg 生成的视频，Rust 通过回环 HTTP 校验请求和先识别、后答复的顺序。完整长视频分段、语音和字幕理解仍未实现。 |
| 表情包 | 本地选择 dsh-meme 清单和图片，按标签匹配后批量保存于当前人格。与既有表情选择、心情匹配及自动发送共用本机表情库。此功能使用公开清单格式，本次未接入在线资源商店。[上游清单说明](https://github.com/yyh-001/dsh-meme/blob/821aa2496808af75771b67fecc8d9875f1a5012e/docs/remote-pack-spec.md) |
| 语音 | 保留系统朗读与转写，以及按人格选择的第三方 TTS、连接检查、试听和自动朗读。已跑合成接口夹具，实际服务和音色待实机验证。 |
| 安全配对 | 沿用 mTLS 认证连接和三类 API 配置交接。电脑出码授权及手机接收冲突时保留本机配置的规则继续适用。已有 Rust 回环测试覆盖身份、数据、配置及离线重试，真实家庭局域网和相机仍待验证。 |
| 生命周期与更新 | 既有主动消息随机延迟及「关于」的正式更新入口保留。Rust 验证了更新下载和校验规则。当前候选与公开包版本号一致，更新检查仅推荐更高的正式版本，实际安装更新仍需设备验收。 |
| 数据兼容 | 沿用 schema 10 和原数据库路径、迁移、关系算法及角色资源，SQLite 回归覆盖原有记录、人格回收站及同步。 |
| B站、虚拟日常图片和视频生成 | 尚未接通。当前网络无法访问 B站开放平台与百炼服务，需要官方授权、可用的模型和服务账号，才能完成真实验证。 |
