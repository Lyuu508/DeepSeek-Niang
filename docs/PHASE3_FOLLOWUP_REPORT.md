## 记忆怎样保持且控制成本

原始聊天永久保存在本机 SQLite；新增外部内容 FTS5 trigram 索引只占本机空间，不把整库上传。每次回复先检索人格隔离的结构化记忆，再在剩余预算中检索相关旧聊片段。最近上下文已含的文本不重复，片段标注来源消息 ID、角色和时间；历史助手文本不能当成主人事实，也不能作为系统指令。每片段最多160字符，有限候选/条数/预算，适合中文主题检索。

手动编辑或删除过的结构化记忆，其来源聊天不会从旧聊检索重新进入请求；隐私/删除、未完成分支、明显密钥/密码和其他人格均过滤。关闭人格记忆开关同时关闭两类检索；关闭聊天历史不会额外检索旧聊。主人仍可在陪伴页查看/编辑/标记重要记忆。对于模糊的“之前那件事”，补充人物或话题更容易检索；这不是无限无损的模型记忆。

记忆提取、索引、检索、关系与情绪规则没有新增模型请求或 embedding 服务。它们会把有限相关证据加入原来的单次聊天请求，因此仍消耗这部分输入 Token；不宣称“记忆完全免费”。每日用量继续按实际提供商回报和用途记录，没有真实 Key 不报告实际节省比例。
