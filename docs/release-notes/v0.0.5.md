# DeepSeek娘 v0.0.5 测试版｜连续计划、生活日记与主动分享

本版完善了角色的虚拟日常：让计划延续多天，保留活动进度，并留下可查看来源的日记、兴趣和分享记录。

## 本版更新

- 多日计划：保存步骤与进度，支持暂停、恢复和取消。
- 生活日记：按日期查看虚拟活动、聊天及情绪记录。
- 兴趣变化：保留计划经历与变化原因。
- 活动恢复：退出或重启后依据已保存进度恢复，不补算离线工作。
- 主动分享：增加交流模式、独立模型开关、Token 预算、阅读状态和本机通知。

## 安装与升级

- 升级前保全数据，完全退出旧程序，不要先卸载、清数据或删除数据库。
- 请同时更新电脑和手机到 v0.0.5，旧版混用可能无法同步。
- Android 保持 `io.local.deepseekcompanion.test2`，版本代码为 1005；已核对与 v0.0.4 test2 的签名一致，满足该身份更新条件，真实手机覆盖升级仍待验收。
- 不能覆盖 v0.0.1 原身份或早期 `.test` 应用，也不能自动读取它们的私有数据。签名冲突时请停止，保留旧应用。
- Windows 沿用自签名测试证书，不是公共 CA 信任的发布者，不要为安装而关闭系统防护。
- 聊天需要自己的 DeepSeek API Key。主动模型分享需要单独开启，会产生 API 用量；普通虚拟日程和结构化日记不调用模型。
- 扫码还会授权将电脑已有 Key 配置到本次认证手机，重扫可能更新手机配置；仅向可信手机展示。解除配对不使提供商 Key 失效，必要时删除或轮换。

## 已知限制与待验证项

- 虚拟学习、阅读和创作是应用内安排，不代表真实浏览、视频理解或完成外部作品。
- 生活任务仅在 Windows 应用运行时推进；手机读取同步记录。没有云推送，强制停止应用后不保证送达。
- 家庭局域网、真实 DeepSeek、Android 覆盖安装和通知呈现仍待用户设备验收。
- Windows 发布截图仅显示空白主窗口，尚需核实是截图时机还是界面加载问题；现有启动检查不能证明完整界面正常。若持续白屏，请保留版本和错误信息反馈，不要清除数据。
