# 使用说明

本文面向 v0.0.6 测试版。第一次使用可按顺序阅读；已有用户请先看[升级与数据保护](#升级与数据保护)。

## 下载与安装

| 设备 | 安装入口 | 要求 |
| --- | --- | --- |
| Windows 电脑 | [中文 EXE 安装程序](https://github.com/Lyuu508/DeepSeek-Niang/releases/download/v0.0.6/DeepSeek-Niang_0.0.6_windows-x64-setup.exe) · [详细步骤](INSTALL_WINDOWS.md) | Windows 10/11 x64；WebView2 |
| Android 手机 | [ARM64 APK](https://github.com/Lyuu508/DeepSeek-Niang/releases/download/v0.0.6/DeepSeek-Niang_0.0.6_android-arm64-isolated-test.apk) · [详细步骤](INSTALL_ANDROID.md) | Android 10+、ARM64 |

无需下载源码 ZIP 或安装 Rust、Node.js、Python。使用电脑和手机时，请让两端都处于 v0.0.6。当前不提供 iOS、macOS 或 Linux 安装包。

安装前对照 [SHA256SUMS.txt](https://github.com/Lyuu508/DeepSeek-Niang/releases/download/v0.0.6/SHA256SUMS.txt) 核对文件。Windows 采用自签名测试证书，系统可能仍提示未知发布者；不要关闭系统防护，也不要导入不明根证书。

在 Windows 顶部打开「桌宠」，勾选「显示桌宠」即可使用。[桌宠操作](phases/05-desktop-pet.md)

## 首次配置聊天

1. 打开应用的“设置”，选择“验证安全存储”。此项使用独立测试凭据，不需要真实 Key。
2. 在本机输入自己的 DeepSeek API Key 并保存。保存后输入框清空，只显示配置状态。
3. 回到默认人格，发送一条消息。聊天需要联网、可用 Key 和提供商额度，费用以 DeepSeek 为准。
4. 在“人格管理”创建其他人格；通过设置调整名称、称呼和性格。切换人格不会把回复改存到另一个人格。

同一设备上的多个人格共用本机 Key，用量按人格记录。手机配置好 Key 后可以独立聊天，不要求电脑持续开机。Windows 使用 Credential Manager；Android 使用 Keystore 保护的本机私有存储。不要把 Key 填进浏览器 UI 测试页面、聊天正文、`.env` 或公开反馈。

## 聊天、记忆与关系

每个人格使用一个持续保存的聊天空间。电脑端 Enter 发送、Shift+Enter 换行；手机通过发送按钮发送。生成时可以停止，结束后可以重新生成并查看旧回复。

在“本地数据”中查看、添加、编辑和删除记忆，标记重要性，并决定是否允许相关内容用于 DeepSeek 聊天。自动整理仅识别部分明确表达，例如以“请记住”开头的内容；重要信息应核对后手动保存。发现冲突时，核对来源再确认采用新值或保留旧值。

旧聊天长期保存在本机，但不会每次全量发送。系统按当前话题查找有限片段，与长期记忆共用预算；使用具体人名、地点或主题有助于检索，不保证所有模糊提问都能命中。在陪伴设置中关闭记忆上下文可关闭两类检索，关闭聊天历史也会停止额外旧聊检索。

“关系与日常”展示五维关系、情绪及来源。普通问候不固定增加好感；关系和情绪会加入聊天上下文，但真实模型的表达效果仍待体验验证。

## 连接电脑与手机

1. 确认两端均为 v0.0.6，手机与电脑处于可互访的局域网。电脑可用网线，手机连同一路由器的普通 Wi-Fi；访客网络或设备隔离可能阻断连接。
2. 电脑进入“局域网同步”，点击“连接手机”生成短期二维码。只向自己信任的手机展示。
3. 手机进入连接页点击“扫一扫”，允许相机并扫描电脑上的二维码。等待真实同步结果，不以“设备已发现”代替成功。
4. 核对同一人格的聊天和记忆，必要时使用“手动同步”。离线后本地已有记录仍可查看，重新连通并打开应用后再补传。模型聊天仍需互联网。

**生成二维码也会授权本次手机 API 配置。** 已认证手机会通过单独的加密连接取得电脑已配置的 Key，并写入手机安全存储；二维码和普通同步不含 Key。重新扫码可能更新手机已有 Key，电脑没有 Key 时不覆盖手机现有配置。若手机存储失败，仍需单独检查 Key 状态，不能把同步完成当作 Key 一定可用。

解除设备配对会阻止后续同步，但不能撤销已复制 Key 在 DeepSeek 的使用权。如需撤销，还需删除手机 Key 或在提供商处轮换 Key。

Windows 网络提示仅按需要允许此应用访问专用网络，不关闭整个防火墙，也不开放路由器公网端口。失败排查见 [FAQ](FAQ.md#扫码后无法同步怎么办)。

## 虚拟生活与主动分享

Windows 应用运行时，具有执行权限的电脑推进虚拟日常；手机查看同步的记录，不重复执行电脑任务。计划可以延续多天，在当前活动之后开始；每步完成后至少间隔 24 小时继续，不代表每天固定时刻执行。

在陪伴页可以查看当前进度、暂停或恢复任务、取消任务及关联计划，并浏览历史日期日记和兴趣来源。应用退出后不补算学习时间，也不会声称关机期间完成了外部任务。

新建配置中主动消息、模型生成和系统通知默认关闭；升级保留原设置。若需要主动交流，在陪伴设置中开启主动消息、选择模式、设置安静时段并保存。模型生成有单独开关和 Token 预算，不开启时使用简短本地规则分享；开启后会消耗 API 用量。通知还需本机系统授权，没有云推送或强制后台保活。

日程、结构化日记与本地规则整理不调用模型；被允许引用到聊天中的资料仍会产生输入 Token。实际用量以提供商返回为准，未知费用不等于免费。参见[费用说明](PHASE4_COSTS.md)。

## 升级与数据保护

**不要为了安装、同步或排错先卸载应用、清除数据或删除数据库。同步不能替代独立备份。**

| 已安装的 Android 应用 | 与本版的关系 |
| --- | --- |
| v0.0.4 的 `io.local.deepseekcompanion.test2` | 本版同身份、同证书，版本代码从 1004 增至 1005；满足更新条件，真实手机覆盖仍待验收 |
| 更早的 `.test2` 测试版 | 保持该测试身份；本次发布直接核对的是 v0.0.4，新旧跨度的实际升级仍需单独验证 |
| v0.0.1 原身份或早期 `.test` | 不能由本版直接覆盖，也不能自动读取旧私有数据；保留旧应用，完整跨身份迁移尚未实现 |

升级前记录两端版本，完全退出旧进程。Windows 保留当前用户应用数据目录的完整副本，而非只复制运行中的 `companion.sqlite3`；数据库可能还有 WAL 文件。备份应受访问控制，不上传 GitHub。Android 自动云备份被禁用，当前没有一键完整加密导出工具；系统不允许导出时保留旧安装和数据，不 root 或绕过沙箱。

首次打开旧库会在私有目录执行一致性备份及事务迁移；这不等于独立、离机或加密备份。v0.0.6 使用 schema 8，具体机制见[迁移说明](PHASE4_MIGRATION.md)。Windows 自签名安装和窗口出现已有 Hosted runner 检查，不代表用户旧安装覆盖已验证。

升级后若有新聊天，不要直接用旧备份覆盖或安装旧版强行降级。遇到错误先停止操作，保存当前库、相关 WAL 和已有备份，核对后再恢复；本版没有一键无损降级。

## 反馈问题

到 [Issues](https://github.com/Lyuu508/DeepSeek-Niang/issues) 提供两端版本、系统版本、发生步骤、时间和脱敏错误码。遇到持续白屏可说明窗口能否出现、是否已安装 WebView2，保留数据后反馈。

不要公开 API Key、二维码、私钥、私人聊天、数据库或完整未经审查的日志。自动化与实机检查的区别见[验证说明](VALIDATION.md)。
