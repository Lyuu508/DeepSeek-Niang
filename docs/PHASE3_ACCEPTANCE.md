# v0.0.3 安装、备份与主人实机验收

这些项目尚未在主人设备执行。自动化、Hosted 原生安装与官方 APK 验签见同版本 BUILD-RESULTS.json，不等于以下清单已通过。

## 安装前

1. 从 v0.0.3 Release 直接下载 EXE/APK、SHA256SUMS.txt。核对 SHA-256 和 BUILD-RESULTS 两端同一完整源码 SHA，不下载 Actions ZIP 作为安装前提。
2. 保留旧应用，不卸载、不清数据。记录当前 Android 应用名、版本、applicationId；本版仅更新 `io.local.deepseekcompanion.test2` 的“DeepSeek娘 扫码测试版”。早期 .test / 原正式版不支持覆盖。若提示签名不兼容，停止，不通过卸载消除错误。
3. 退出两端应用。保留 Windows 原私有数据目录的完整备份，勿上传数据库；Android 按系统可用的本地受控备份方式保全。首启在私有目录生成一致性 `.pre-v6-UUID.bak`，它不能替代离机备份。系统限制不能导出时先保留现有安装和数据，不 root 或绕过沙箱。
4. EXE 是中文安装器，沿用现有自签名测试证书，系统安全提示可能仍存在。不要因此关闭系统安全工具或导入未知公共根证书。
5. 安装两端，再打开正确的 test2 图标。新版版本 0.0.3 / Android1003，两端 schema 6，不与旧端混用。Windows 可用网线，手机连同一路由器 Wi-Fi；访客网/AP隔离/VLAN可能阻断，勿开放公网端口。

## 遇到迁移或数据异常

先关闭应用，保留当前库、WAL相关文件和所有备份，不重复卸载/清数据。迁移失败自动回滚；成功升级后恢复旧备份会遗漏新写入，须在副本中核对后受控恢复，本版无一键无损降级。不要把真实聊天、API Key、私钥或数据库贴到公开 Issue；可提供版本、脱敏错误码、发生步骤和时间。

原正式 v1 或早期 .test 的完整跨身份迁移仍待另行实现，不能从 test2 直接读旧 Android 私有数据。已有电脑端同步数据可再向本版同步；未同步手机数据先留在旧版。未来方案须先安全导出/完整备份、确认来源、保留消息 ID、事务去重导入及回滚，主人确认前不迁移或删除。

验收后再决定下一阶段，本版本结束不自动开展阶段 4。
