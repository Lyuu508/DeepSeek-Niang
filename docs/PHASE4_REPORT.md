# 阶段4实现报告 · v0.0.5

基线为已发布 v0.0.4 的 `30feb9ca686f3be33b9def962b7a0db3d15e815f`。本次用户明确授权阶段4开发、测试、推送、同源双端构建和 v0.0.5 Pre-release。最终源码 SHA、原生结果和实际包散列以发布附件 BUILD-RESULTS.json 为准；本文件不预先宣称原生构建或实体设备通过。

## 实际实现

1. 扩展原有 `companion_activities` / `companion_life_events` / `companion_proactive`，没有另一套生活数据库。起床、休息、学习、阅读保存的话题、整理记忆、回顾聊天、兴趣构想、创作构思、日记和分享均明确为虚拟活动。保留旧 video/music 活动记录，但标注“话题构想，未播放”。没有接入 B站、桌宠或语音。
2. 原 `life_plans` 保存连续1–30步计划、进度、下次时间。自动模式从人格偏好生成一次可持续三天的初始安排；用户可新建计划。每步完成后至少24小时再继续，不因重启、午夜或时区重置。新计划在当前活动之后开始。
3. 活动使用原 `task_queue`、租约、fence、boot ID、递增权威 epoch、`task_checkpoints` 和日志。每次领取与结果写入验证权限；进度、检查点、完成事件、兴趣、重要记忆和分享候选在同一事务提交。暂停/恢复/取消操作同样原子完成。取消计划步骤会取消关联计划；失败允许用户重试。
4. Windows 原生进程存活时运行调度；租约使用进程单调计时。心跳断层或进程重启暂停，依据已提交检查点恢复相同活动 ID；离线时间不补算工作。已完成事件是幂等依据。本地纯虚拟活动可安全核对后恢复，外部模型不确定请求不自动重放。
5. Android 独立聊天、读取本地 SQLite 和同步同一人格的生活记录；不运行 Windows 生活执行器。已有 host 绑定不可被副本抢占；未绑定时只有人格来源档案可建立本地主机，不做断网双主自动选举。迁移 NAS 以后复用 headless core/ChatService 与任务接口，需增加明确的权威交接协议；本版不依赖 NAS。
6. 主动分享默认保留旧用户开关；关闭/安静/自然/活跃/自定义、关系阶段、实际聊天繁忙与最近互动、候选来源、安静时段、滚动日限额控制是否发送。普通休息、起床、等待不生成分享候选；同一完成事件只产生一条消息。
7. 模型生成另有默认关闭的开关。开启并且本机有 Key、来源与预算合格才使用原 DeepSeek 流式客户端；现有人格、关系、情绪和允许 API 的相关记忆参与生成。普通日程和结构化日记不调用模型。前台聊天抢占后台生成，换/删密钥等待取消完成。设置关闭后不发布迟到结果。
8. Token 预算先按输入 UTF-8 字节加输出上限和协议余量保守预留；确认 usage 后按实际记录，未知请求保留预算，不自动重试。日/周与活动分类统计实际 Token，人民币费用没有价格证据时显示未知。
9. 原 `character_interests` 保存有原因的、边际递减的计划兴趣变化和来源历史。完成重要多日计划时最多每天2条生活记忆、默认本地私有，有事件外键；确定 ID 去重，用户修改/删除的同 ID 不重建，不覆盖用户置顶或手动记忆。角色自己的活动不自动增加主人好感。
10. 日记是既有生活事件、聊天和持久情绪的日期视图，无模型调用和重复记忆库。按人格/时区分组，区分虚拟事件、实际聊天记录和应用情绪；可以查历史日期。
11. 保持桌面顶部、左人格、中央聊天和右状态/设置及手机扫码布局。新增已提交进度、开始/更新时间、累计时长、计划、任务控制、日记、兴趣、分享、Token 统计。手机不能控制另一设备的唯一任务，过期状态明确显示。
12. 消息送达、每设备未读/已读、通知处理分别记录。Tauri 官方即时通知插件，用户开启后申请本机系统权限；通知正文不包含私人聊天内容。`sending` 表示请求正在交给 OS，异常退出不会自动重复；`shown` 表示通知 API 接受，不宣称用户已阅读。没有云推送、开机自启通知恢复、定时通知或 Android 保活。

## 验证与范围

本地完整回归：142项 Rust、24项 Python、5项 Node、69项品牌资源校验、schema/FK/完整性、Clippy `-D warnings`、TypeScript/Vite。显式浏览器夹具32项×普通/测试包两种模式。原21项不变量和既有聊天、配对、二维码、记忆及好感度均保留。没有把 Mock 回复当成真实 DeepSeek。

新增核心测试覆盖三天连续计划、同 ID 重启恢复、暂停/恢复、取消、失败重试、结果去重、fence/epoch/租约、Android 不执行、过期/离线状态、跨午夜/时区、关闭无请求、预算先拒绝、迟到结果、未知账单、人格隔离、日记、关系不加分及 schema7 升级/失败回滚。真实回环 TLS 测试覆盖生活成果/重要记忆/分享与回执双向同步不重复。实际回环 HTTP 测试覆盖主动模型请求格式、中文流、实测 usage、无 Key/关闭不连接。

Hosted Windows 原生编译、中文安装/启动、原 Windows 自签名；Android ARM64 原生编译、现有持久签名、官方 apksigner 与实际 v0.0.4 APK 对照，均由门禁执行后记录到 BUILD-RESULTS.json。未完成门禁时不公开安装包。本地 Linux 成功不代表 Windows 成功。

## 实际限制与下一步

实体 Windows/Android、家庭有线/Wi-Fi、真实 DeepSeek 和通知在具体系统的呈现需用户验收。Android 没有云推送，被停止或系统冻结时不能保证送达。生活学习/创作是虚拟时段与资料回顾，不能声称完成真实课程、完整作品或外部知识验证；可检查已保存来源/检查点。首次默认主机来源规则不支持多个离线 Windows 自动竞争接管，也不在本版实现 NAS 迁移授权界面。时区设置沿用偏移量，夏令时变化需重新保存；配额使用滚动24小时保护。日记视图每类有上限，历史原始数据不删。

阶段5仅准备复用当前状态/情绪接口，不开发桌宠。v0.0.5 发布后停止。
