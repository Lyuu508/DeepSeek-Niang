# 常见问题

以下回答以 v0.0.5 测试版为准。[返回使用说明](USAGE.md)

## 使用需要付费吗

聊天使用你自己的 DeepSeek API Key，API 费用由提供商收取。允许模型生成主动分享时也会产生用量。虚拟日程、结构化日记、本地记忆整理和检索不另行调用模型，但检索结果加入聊天仍消耗输入 Token。应用没有可靠价格信息时显示未知，不应视为免费。

## 能离线聊天吗

当前模型回复需要联网访问 DeepSeek，不包含离线大模型。没有网络时仍可查看本机已有聊天和记忆。手机配置自己的 Key 后可以独立聊天，不要求电脑开机；虚拟生活执行仍依赖 Windows 应用运行。

## 软件会把所有聊天上传吗

每次请求发送当前人格设定、本次输入，以及设置允许的有限近期聊天、相关记忆和旧聊摘录，并非整个数据库。可在设置中关闭历史或相关检索，长期记忆也有是否允许用于模型的控制。不要把其他人格隔离误解为操作系统层面的多用户安全隔离。

## 为什么它没有记住之前说过的事

保存历史和模型每次能看到历史是两回事。自动记忆采用本地规则，旧聊按话题及预算检索，不能保证所有内容或模糊问法都命中。重要信息可在“本地数据”中手动保存、核对、标记重要，并选择是否允许用于聊天；提问时补充具体主题也有帮助。

## 扫码后无法同步怎么办

先检查两端版本是否均为 v0.0.5，并打开应用。手机和电脑需要网络可互访，访客 Wi-Fi、客户端隔离或不同 VLAN 可能阻断连接。电脑可接网线，不需要两端都用无线。

按需要允许此应用访问 Windows 专用网络，不关闭整个防火墙、不映射公网端口。二维码过期可重新生成；新码也会重新授权本次 Key 配置，只给可信手机扫描。查看固定错误码和实际同步状态，尝试“手动同步”。版本错误、签名错误和数据错误应分别反馈，不通过删库或清数据排除。

## 扫码会把 API Key 给手机吗

会，电脑生成二维码时包含本次授权：本次认证手机通过另一条加密连接取得已配置 Key，写入自己的系统安全存储。Key 不写在二维码、普通同步数据或业务数据库中。重新扫码可能更新手机已有 Key；电脑未配置 Key 时保留手机配置。同步成功不保证系统 Key 保存成功，还需看手机的配置状态。

解除配对不等于撤销提供商 Key，需要时删除手机 Key 并在 DeepSeek 平台轮换。不要公开二维码。

## Android 提示签名冲突或无法覆盖怎么办

停止安装并保留旧应用，不要先卸载或清数据。本版为 `io.local.deepseekcompanion.test2` 的“DeepSeek娘 扫码测试版”，与 v0.0.1 原身份及早期 `.test` 不同，不能直接覆盖或自动读取其私有数据。v0.0.4 test2 与本版已核对同证书、版本代码递增，但实际手机覆盖升级仍待验收。见[升级说明](USAGE.md#升级与数据保护)。

## Windows 提示未知发布者怎么办

当前安装器使用自签名测试证书，不是公共 CA 信任的发布者；有签名不代表没有 SmartScreen 提示。只从官方 Release 下载，核对 SHA-256，保留系统提示用于排查，不关闭系统防护，也不安装来源不明的根证书。

## Windows 打开后持续白屏怎么办

先保留原数据，记录版本、Windows 版本、是否有错误提示，以及 WebView2 是否已安装；可从[微软官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)检查运行库。不要通过删除应用数据或关闭防护排错。

目前发布截图仅显示空白主窗口，检查脚本只验证进程及窗口出现。它不足以确定白屏原因，也不能证明完整内容渲染正常；尚无已验证的通用修复方法。请提交脱敏反馈，具体证据见[待核实问题](VALIDATION.md#待核实问题)。

## 她真的在看视频或学习吗

当前生活活动是明确标记的虚拟安排，没有真实网页浏览、媒体播放或视频理解。日记依据已保存事件、聊天及情绪状态整理，不表示角色完成了真实课程或外部创作。桌宠、真实视频理解及语音仍是后续计划。

## 为什么电脑关机后进度和通知停了

Windows 应用存活时才执行生活任务，退出后不补算完成进度；手机只读取同步记录。没有云推送，Android 被系统限制、冻结或强制停止时不保证同步或通知送达。通知接口接受也不等于用户已经看到或阅读。

## 同步是不是备份，删掉记忆是否彻底擦除

同步不是历史备份，误删也可能被传播。记忆删除会停止检索并记录删除标记，但旧事件、其他合法副本或独立备份仍可能含原文。数据库及迁移备份目前未做数据库级加密；没有一键无损降级或完整加密备份恢复工具。

## 可以直接商用、再分发源码或角色素材吗

仓库尚未提供项目级许可证，不能仅因源码公开就推定获得这些授权。代码、第三方依赖和角色素材可能有不同权利要求，应先与维护者确认；本次文档整理没有为项目选择许可证。

## 反馈应提供什么

在 [Issues](https://github.com/Lyuu508/DeepSeek-Niang/issues) 提供两端版本、系统、复现步骤、发生时间及脱敏错误码。不要提交 API Key、二维码、私人聊天、数据库、私钥或未经审查的原始日志。涉及潜在安全漏洞时先看[安全说明](../SECURITY.md#报告问题与敏感资料)。
