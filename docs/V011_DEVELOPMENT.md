# DeepSeek娘 v0.1.1 开发与验收

Windows 与 Android 的版本均为 0.1.1。Android versionCode 为 1012。基于 GitHub 的 v0.1.0 代码 `71bf470` 和已验证的历史发布记录继续开发。

## 已实现的变更

- 双端共用已有正式角色资源和海洋主题。桌面加强透明按钮、悬停和焦点反馈。手机优化设置分类排列和聊天工具触控。统一视频和插件的整块文件选择卡片。
- 本机聊天可拖放、粘贴、选择和移除最多四张图片，可搭配可编辑文字附件。DeepSeek 聊天接收文字描述，图片附件留在设备。聊天输入栏可把视频和问题带到视频中心，经授权让千问识别、DeepSeek 回答，再把问答保存到当前人格。
- 语音输入沿用已有端侧 ASR。系统安全存储可另存 OpenAI Speech 或同协议 HTTPS 服务的 TTS 密钥，支持模型、默认 Voice ID、兼容接口的 Speaker ID、每人格音色、试听和可选自动朗读。支持 WAV，语速沿用语音偏好。服务需要支持实际选用的模型和音色。
- 电脑出码、手机扫码时，原有短期授权与证书校验可交接 DeepSeek、千问和云语音全局配置。不同的本机密钥或设置保留原值并提示冲突。语音与具体人格的绑定仍由手机自行配置。普通 SQLite 复制队列继续只同步非秘密数据。
- 表情库按人格保存在设备。可导入拥有权利的图片，按分类或文件名搜索，预览后添加到聊天。可选按照当前心情附上对应分类的图，十分钟内最多附加一次。评估了 MIT 授权的表情插件和 AGPL-3.0 对话项目的结构与用途。现有按人格的自由、自定义和角色扮演选项继续可用。[dsh-meme](https://github.com/yyh-001/dsh-meme) · [对话项目许可证](https://github.com/xqpsec/dsh-jailbreak)
- 主动消息在已有注册、冷却和安静时段规则下延迟 5–20 秒。当前聊天和密钥变更可取消待发送任务。用户输入后的普通生成维持原有入口。
- 下载进度来自下载流。校验哈希与签名通过后，更新前将 SQLite 的一致快照保存在应用数据目录的 `update-backups`。数据库维持 schema 10，旧版单图记录可继续使用。

## 仍需完成的能力和验收

- 目前的小 MP4 原片限制为 12 MiB。较长或不兼容的视频支持抽样画面与时间点。完整分段、音轨、字幕和长视频全量覆盖仍待完成。
- B站官方扫码登录、登录状态、自动发现与授权播放，以及云端图片和视频生成尚未接入。云环境访问 `open.bilibili.com` 与 `help.aliyun.com` 返回代理 CONNECT 403。现有千问模型配置只用于画面识别。
- 当前配置交接方向为 Windows 到 Android，触发点为显式扫码。手机向电脑的数据配置回传、后台配置变更传播和逐项解决冲突仍待完成。
- 第三方的真实 API 调用、手机与电脑局域网和安装升级需要相应账号与真机。浏览器夹具和回环服务测试为自动化验证。

## 安装身份与正式发布

- GitHub 最新公开的 v0.1.0 APK 使用 `io.local.deepseekcompanion.acceptance` 与证书 `5d92ada7e0187559964c075fb7b285697f6b4357fcea877b5def20b7a15b6c12`。
- 正式应用使用 `io.local.deepseekcompanion`。v0.0.1 APK 的原证书为 `9de96ea5fb1d0b3f91ea73d9a16c030428453b15838927a85f86773eaef208a1`。这两个安装身份分别绑定各自的应用数据。
- 当前云环境缺少原证书对应的签名配置。在具备原签名、安装验收及必要功能验证后再创建正式 v0.1.1 Release。仓库 Actions Secrets 列表接口的 403 只反映调用权限。
