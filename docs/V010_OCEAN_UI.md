# v0.0.10 海洋主题

基于 GitHub main `939d78802e0e5a6c4ce99a938b97ce498a1bb1b0` 开发。Windows 保留品牌导航、中央聊天和右侧角色面板，Android 保留 48px 聊天顶栏、至少 44px 的输入按钮命中区域和紧凑底栏。新页面统一使用海洋插画、玻璃卡片与线性图标。可在设置选择海洋蓝、贝壳紫或海沫青，使用浅色、深海夜色或跟随系统。

## 组件与素材

| 位置 | 实现 |
| --- | --- |
| 应用外观 | `design-tokens.css` 管理色彩、圆角、字体和动效，`ocean.css` 统一布局、卡片与海洋背景 |
| 按钮与弹窗 | 保留指针起点渐变和键盘焦点，触屏采用按压反馈。沿用原生 dialog、键盘关闭和危险操作确认 |
| 人格与聊天 | 默认头像使用三视图生成素材，自定义人格保留自己的名称和配置。代码围栏以可横向滚动的纯文本呈现 |
| 角色状态 | 五项关系数值与虚拟活动读取原有快照。默认人格的表情由持久情绪和正在进行的活动选择 |
| 设置 | 外观、凭据、人设、语音和桌宠分类。字体使用原有 SQLite 设置。主题存于本机 WebView |
| 视频 | Windows 保留本地解码、转写和时间线。Android 展示当前人格已保存的视频摘要，电脑保存到长期记忆后可按原协议同步 |
| 关于 | 全身立绘和可切换的角色表情；本人格图像之外还有独立的晴天、夜色、设置、插件和海浪背景 |

正式角色只参考用户提供的三视图，两个 UI 概念图用来确定层次、色彩和布局。角色生成后分切为 16 个具有透明通道的独立文件，包含头像、表情、动作、全身与同一立绘裁切的半身图。5 张不透明图作为独立背景。App 原图标及 Android Launcher 衍生资源继续使用原始海滩图。[素材尺寸、用途和摘要](../assets/branding/ocean-art.json) · [实际资源](../apps/companion/public/branding/ocean)

应用启动时无需生图服务。资源在构建中检查格式、透明通道、像素尺寸与 SHA-256，合计约 846 KiB。主题控件不读取用户聊天或 API 凭据。

## 数据与升级

Windows 应用身份 `io.local.deepseekcompanion` 和 Android 测试包 `io.local.deepseekcompanion.test2` 继续沿用。Android 版本代码为 1010。应用继续使用 schema 10，聊天、人格、同步、回收站、凭据和桌宠的原机制仍适用。[现有迁移说明](V009_RECYCLE_MIGRATION.md)

## 验收范围

- 浏览器回归以合成 IPC 数据检查 Windows 和 Android 的聊天、人格、设置、插件、视频、本地数据、同步、陪伴和关于。每个页面分别在浅色和深色下检查。
- 截图包含回收站、移入和永久删除确认、两个设备的字号大图、配置保留及手机模拟输入法。竖屏布局含 360×800、375×812、393×852、412×915、1024×768 和横屏。
- Windows runner 验收已签名 EXE 的实际安装、启动和应用窗口截图。Android ARM64 APK 逐项检查包名、版本、图标、角色素材和 v0.0.9 test2 签名。
- 实机检查使用 Windows 和 Android 两端同一版本。检查 Android 桌面、旋转与中文键盘、读取旧聊天、字号和暗色。测试真实聊天、语音、局域网配对，以及保存后同步的视频摘要。
