# v0.0.9 双端界面

Windows 保留左侧人格、中央聊天和右侧陪伴设置。Android 聊天页使用 48px 顶栏、可展开输入工具和 53px 底部导航。语音、发送范围、设备连接、关系与日常、记忆和插件均可从输入工具或侧栏打开。Android 的键盘、刘海和导航栏空间由 MainActivity 的 WindowInsets 处理，WebView 以收到的输入法状态决定是否显示底栏。[手机竖屏反馈](https://github.com/Lyuu508/DeepSeek-Niang/issues/2)

## 375×812 布局测量

| 指标 | v0.0.8 主线基线 | v0.0.9 |
| --- | ---: | ---: |
| 顶栏 | 66px | 48px |
| 底栏本体 | 63px | 53px |
| 输入区 | 206px | 61px |
| 可见聊天区 | 447px | 650px |

两次使用同一份 Chromium 聊天夹具、相同视口、系统语音入口和独立测试包设定。测量来自实际渲染元素的边界框，聊天区增加 203px。问题帖的 560px 来自更早的实测环境。360×800、393×852、412×915、1024×768 和 812×375 的结果与截图随发布证据交付。输入法截图模拟了 WebView 尺寸缩小和输入法事件，真机键盘体验另行验收。

## 原图、图标与字号

原始海滩 PNG 保持 SHA-256。Windows ICO 包含 16、24、32、48、64、128 和 256 像素图层，采用抗锯齿圆角和透明角。Windows 程序与 NSIS 安装器使用同一 ICO。Android 的 72dp Launcher 可见区由原图填满，在 108dp 图层剩余区域延伸原图最边缘像素。圆形和圆角方形遮罩预览读取打包用图层。头饰、眼睛和比耶手势均保留。[Android 图标遮罩预览](../assets/branding/android-mask-preview.png)

视觉变量集中在 design-tokens.css。常规桌面按钮从鼠标进入位置展开径向颜色，约 270ms。键盘焦点有可见描边。系统减少动画时立即显示状态，触屏使用按压反馈。主要文字使用 rem，字体可实时设置为 85% 至 150%。本机 SQLite 保存设置，放大时尽量保留第一条可见消息的位置。桌宠在收到下一次原生状态快照时同步字号。

## 实机验收

- 在 Windows 启动主客户端和桌宠，检查任务栏和安装图标、浅深色、鼠标进入位置、键盘焦点及 150% 字号。
- 在 Android 检查圆形和圆角方形桌面、手势和三键导航、刘海和挖孔、中文输入法打开与关闭，以及横屏输入。
- 用实际设备测试两个版本升级后的聊天、草稿、头像、回收站、插件和桌宠关联。浏览器证据使用合成记录。
