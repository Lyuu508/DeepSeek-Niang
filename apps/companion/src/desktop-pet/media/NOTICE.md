# 桌宠动画署名

待机动画《待机呼吸休闲》、走路动画《螃蟹走路》和点击动画《点击回应-元气挥手》来自 PC2005-cloud/dsh-pet。采用提交 `fb38ce620576f5ed3735a99536d2b1a4a9eb313f` 中的素材。鲸鱼娘原型「溟月」由**上善无形**创作，DeepSeek 版女仆鲸鱼娘由 **ZipZipPipe** 设计。[原项目](https://github.com/PC2005-cloud/dsh-pet) · [上游许可及署名](https://github.com/PC2005-cloud/dsh-pet/blob/fb38ce620576f5ed3735a99536d2b1a4a9eb313f/README.md#许可) · [形象授权声明](https://www.bilibili.com/opus/1247156596114456581)

这里的动画和静帧沿用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)。作者署名、非商业使用及衍生素材的相同许可适用于这些文件。

| 文件 | 源素材 | 转换 |
| --- | --- | --- |
| `standing.png` | 待机呼吸休闲 | 保留透明通道，裁剪第一帧 |
| `idle.webp` | 待机呼吸休闲 | 裁剪并以 12 fps 转成透明循环 WebP |
| `walk.webp` | 螃蟹走路 | 裁剪 2.25 秒后连续 5.8 秒的走路段，以 16 fps 循环 |
| `wave.webp` | 点击回应-元气挥手 | 裁剪 2.25 秒后连续 4.9 秒的挥手段，以 15 fps 播放一次 |

四项资源使用同一 320 × 320 裁剪区。上游下载记录以 Git blob ID 验证，源文件只有带透明通道的 VP9 视频流。桌宠窗口、位置与交互由本项目运行。
